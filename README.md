# Excel Data Analysis Final Project 📊

## 📌 Project Overview

This project was completed as the final project for my online Data Analysis course after completing the Excel module.

The objective of this project is to analyze sales transaction data using Microsoft Excel, identify meaningful business insights, and present the findings through charts, dashboards, formulas, and analytical summaries.

## 🎯 Project Objectives

- Analyze sales and transaction data.
- Calculate key performance indicators (KPIs).
- Identify top-performing products and regions.
- Analyze monthly revenue trends.
- Evaluate customer purchasing behavior.
- Perform What-If Analysis and regression calculations.
- Present business insights through a dashboard and visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Excel Formulas and Functions
- Conditional Formatting
- Charts and Data Visualization
- What-If Analysis
- Regression Analysis
- Data Analysis and Reporting

## 📂 Project Contents

The Excel workbook includes the following sections:

- **Dashboard:** Summary of sales performance and key findings.
- **Raw Data:** Transaction-level dataset for analysis.
- **Analysis:** Product, regional, monthly, category, and customer analysis.
- **Visualizations:** Charts showing sales performance and trends.
- **What-If Analysis:** Discount scenarios and estimated profit calculations.
- **Regression:** Regression statistics and descriptive analysis.
- **Formula Lab:** Examples of Excel formulas and functions.
- **Submission Checklist:** Overview of project requirements and remaining tasks.

## 📈 Key Analysis Areas

### 1. Sales Performance Analysis
Analyzed transaction data to understand revenue, sales volume, and overall performance.

### 2. Product Analysis
Compared products based on revenue and units sold to identify top-performing products.

### 3. Regional Analysis
Examined revenue across regions to identify high-performing markets.

### 4. Monthly Sales Trends
Organized revenue by month to understand sales patterns over time.

### 5. Customer Analysis
Evaluated customer revenue, transaction frequency, and repeat purchasing behavior.

### 6. What-If Analysis
Explored different discount scenarios to understand their potential impact on revenue and estimated profit.

### 7. Regression Analysis
Calculated regression statistics to explore the relationship between sales quantity and transaction amount.
